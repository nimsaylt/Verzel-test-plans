# BUG-002 — Campo de e-mail aceita endereço inválido durante a finalização da compra

| **Ambiente** | Ambiente de demonstração / QA — URL do projeto não informada no material |
| **Aplicação / Módulo** | Checkout / E-mail |
| **Navegador / Dispositivo** | Chrome — versão não informada |
| **Build / Versão** | Não informado |
| **Pré-condições** | Acessar a loja de demonstração e avançar até o formulário de finalização da compra. |

## Passos para reproduzir

1. Acessar a loja.
2. Adicionar um produto ao carrinho.
3. Avançar para **Finalizar compra**.
4. Informar no campo E-mail um valor malformado que contenha `@` e `.`, mas não seja um endereço válido.
5. Preencher os demais campos.
6. Tentar confirmar o pedido.

## Resultado esperado

O sistema deve validar o formato do e-mail e apresentar uma mensagem clara junto ao campo, impedindo a finalização até que seja informado um endereço válido.

## Resultado obtido

Segundo a descrição fornecida, o campo aceita dados inválidos desde que contenham `@` e `.`.

## Severidade

**Alta** — pode permitir registrar pedidos com e-mail inválido, prejudicando comunicações e acompanhamento do pedido.

## Prioridade

**Alta** — validar antes de concluir a compra, principalmente se o e-mail for usado para confirmação do pedido.

## Causa raiz / Observações

**Hipótese:** a validação pode verificar apenas a presença dos caracteres `@` e `.` em vez de validar a estrutura do endereço. Reproduzir e confirmar o comportamento atual.
