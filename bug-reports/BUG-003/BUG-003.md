# BUG-003 — Carrinho calcula frete e total incorretamente após alterar quantidade com cupom aplicado

| Campo | Valor |
|---|---|
| **ID** | BUG-003 |
| **Título** | Carrinho calcula frete e total incorretamente após alterar quantidade com cupom aplicado |
| **Data** | 2026-10-08 |
| **Reportado por** | Yasmin |
| **Ambiente** | Ambiente de demonstração / QA — https://verzel-store.qa-test-verzel-store.workers.dev/ |
| **Aplicação / Módulo** | Carrinho / API de cálculo |
| **Navegador / Dispositivo** | Chrome — v154.0.8037.98 |
| **Build / Versão** | 	Verzel Store v2.3.0 (VZS-142, publicada em 30/09/2026) |
| **Pré-condições** | Produto “Mochila Urbana 20L” disponível por R$ 100,00; cupom `BEMVINDO10` aplicável; regra do cenário indica frete grátis para subtotal de R$ 200,00. |

## Passos para reproduzir

1. Adicionar 1 unidade de **Mochila Urbana 20L** ao carrinho.
2. Aplicar o cupom `BEMVINDO10`.
3. Aumentar a quantidade para 2.
4. Consultar os valores exibidos e/ou enviar a requisição para o endpoint `/api/carrinho/calcular` com quantidade 2.
5. Comparar subtotal, desconto, frete e total com os valores esperados do cenário.

## Resultado esperado

Para 2 unidades:

- Subtotal: **R$ 200,00**
- Desconto: **R$ 20,00**
- Frete: **R$ 0,00**
- Total: **R$ 180,00**

Ao voltar para 1 unidade:

- Desconto: **R$ 10,00**
- Frete: **R$ 19,90**
- Total: **R$ 109,90**

## Resultado obtido

Na resposta da API fornecida para 2 unidades:

- Subtotal: R$ 200,00
- Desconto: R$ 20,00
- Frete: R$ 19,90
- `freteGratis`: `false`
- Total: R$ 199,90

O frete e o total divergem do cenário esperado.

## Severidade

**Alta** — valores financeiros incorretos podem levar o usuário a pagar um total diferente do esperado.

## Prioridade

**Alta** — investigar e corrigir a regra de frete grátis/recalculo ao alterar quantidade com cupom aplicado.

## Causa raiz / Observações

**Hipótese:** a regra de frete grátis não está sendo aplicada/recalculada corretamente quando a quantidade muda, ou a API não está considerando o subtotal elegível. Confirmar a regra de negócio e comparar a resposta da API com a interface.
