# BUG-001 — Campo de nome aceita emoji como sobrenome e permite finalizar a compra

| Campo | Valor |
|---|---|
| **ID** | BUG-001 |
| **Título** | Campo de nome aceita emoji como sobrenome e permite finalizar a compra |
| **Data** | 2026-10-08 |
| **Reportado por** | Projeto de portfólio QA |
| **Ambiente** | Ambiente de demonstração / QA — URL do projeto não informada no material |
| **Aplicação / Módulo** | Checkout / Dados de entrega |
| **Navegador / Dispositivo** | Chrome — versão não informada |
| **Build / Versão** | Não informado |
| **Pré-condições** | Acessar a loja de demonstração e ter um produto disponível para compra. |

## Passos para reproduzir

1. Acessar a loja.
2. Adicionar um produto ao carrinho.
3. Avançar para **Finalizar compra**.
4. Preencher o campo de nome com um emoji no lugar ou junto do sobrenome.
5. Preencher os demais dados com valores aceitos pela aplicação.
6. Confirmar o pedido.

## Resultado esperado

O campo deve validar o nome conforme as regras de negócio e impedir a finalização quando o valor informado não atender aos critérios definidos. A regra exata para caracteres permitidos deve ser confirmada com o produto.

## Resultado obtido

Conforme a evidência fornecida, o campo aceita um valor com emoji e o fluxo permite finalizar a compra.

## Severidade

**Média** — validação de dados cadastrais inconsistente, sem evidência de bloqueio do fluxo de compra.

## Prioridade

**Média** — corrigir para manter consistência dos dados e das regras do checkout.
